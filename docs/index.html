02 / PRIORITIES

对已有 mesh 的操作任务，先比较什么？

工程判断 · 尚未实施新模型对照
A

修正后的基线

FoundationPose + 鲁棒输入处理。修复已知的噪点与初始化缺陷，不拿带缺陷的旧基线制造“新方法更好”。

B

不同求解路线

SAM-6D 的点对应路线，与 WAPR 的大角度修正路线分别试验。统一输入、模型尺寸和目标坐标系。

C

遮挡恢复单独评估

视频跟踪是另一项任务。评估 Point2Pose 类方法时，除了恢复速度，还要核对绝对位姿和口沿坐标的一致性。

不能直接互换的指标

更少的候选 ≠ 按比例更快；大角度修正 ≠ 任意平移误差都可恢复；视频更平滑 ≠ 绝对位置更准；模型排行榜得分 ≠ 壶嘴对准保证。

03 / FAILURE ANALYSIS

一个像素，为什么值得先修？

项目内单帧消融 · 非公开基准

一次桌面茶壶估计中，mask 主体外出现一个孤立像素。初始化依赖全部前景的外接框中心，导致初始位置明显偏移。相同输入反复运行，错误也稳定重复。

交互示意 · 非原始现场影像
一个离群点改变极值，使框中心远离主体。

不是“分割错了”就结束了

输入噪点是诱因；初始化对离群点敏感是另一层问题。修复应覆盖两者，而不是仅要求分割模型永远输出完美 mask。

这些数字不能证明什么？
  • 倾角是物体向上轴相对竖直方向的夹角，不是倾倒动作的角度。
  • IoU 对比的是模型投影与同一份原始观测 mask；使用宽 160 的离线渲染，不是人工分割准确率。
  • 深度残差来自同一张输入深度，不是独立传感器真值。深度几何仍用目标位置提示，不能称为完整无语义识别。
  • 原始影像与生产记录未公开，本站只发布汇总摘要；不能凭这些数字外推所有茶具、遮挡和持物场景。
  • 没有在此案例运行 SAM-6D、WAPR 或 Point2Pose；不要把表格读成不同模型之间的评测。
04 / EVALUATION PLAN

下一轮，怎样公平比较？

建议方案 · 未执行

01 固定输入

相同 RGB-D、相机参数、mesh 尺寸与坐标系；使用相同 mask 比较纯位姿模块，再单独比较各自完整分割链路。

02 覆盖失败类型

正常桌面、孤立噪点、边界缺失、对称外观、反光与缺深度、手部遮挡。初始化同时加入旋转与平移扰动。

03 测量任务几何

独立标注或测量壶嘴与口沿位置；报告姿态误差、严重错误率和重复稳定性。不要只看外观重合。

04 计完整成本

区分冷启动、模板/模型准备、分割、位姿推理与失败恢复；报告相同硬件下的耗时分布，而非挑最快一帧。

公共方法比较可参考 BOP 任务定义；任务内仍需补充壶嘴、口沿等操作相关指标。本页不汇总不同设备、输入和计时口径的 FPS 排行。

05 / SOURCES & SCOPE

回到原始来源

论文能力来自作者资料；接入优先级属于本站工程判断。发表年份不等同于代码首次公开时间，仓库可访问也不代表已经在本项目复现。

    分割、深度、位姿与重建，不应混为一谈

    SAM 类方法主要回答目标区域在哪里；双目深度回答距离；物体位姿估计回答 mesh 的位置与朝向；重建方法准备几何资产。某个模块升级，不会自动修复其他模块的误差。
